# ElfStory — Roadmap

Phases are gated on verification, not dates. A phase is done when STATUS.md
can state its claim with evidence behind it. Sequencing follows the
Nov 14, 2026 adversarial audit and Garth's picks from its decision pack.

## Phase 0 — "Ship-safe" (P0 fixes — Garth's pick, Nov 14, 2026)
- Close the 3 unbounded exploits: Vex's repeatable +15g tip, Runeforge value compounding on rune swaps, duplicate Whispering Bells in side dungeons (+ gated bell interaction in App).
- Confirmation on destructive actions: slot delete, New Adventure over an occupied slot, Play Again; remove Enter/Space auto-start on Title and auto-Play-Again on Game Over.
- Autosave: local save every 25 turns while playing + save on tab hide/close; persist mute and zoom preferences.
- ErrorBoundary around the app so a render crash shows a recoverable screen instead of a white page.
- Regression tests for the 3 exploits in `tests/engine.test.ts` style.
- Gate: `npm test` green including new regression tests, `tsc --noEmit` clean, `npm run build` clean, and each exploit's repro from the audit no longer works.

## Phase 1 — "Difficulty that scales" (P1 — DONE Nov 14, 2026; sim-verified, see STATUS.md and `tools/difficulty_sim.py`)
- Rebalance early game: enemy HP bases up ~2–3× and/or player ATK growth down, so floors 1–7 are fights, not one-shots.
- Scale story bosses to expected arrival level (Malakor especially; current: dies in 3–4 basic attacks); fix the inversion where side boss Kaelthar (359 HP / 57 ATK) massively out-stats the final boss.
- Scale Crimson Draught healing and companion HP/damage with level/depth (companion currently flat 24 HP, perma-dead from ~floor 5).
- Decide the intended Endless Abyss death curve and tune XP curve / enemy ATK growth to land there (currently: level stalls ~20, guaranteed death ~floor 25–40).
- Gate: simulation (audit's `difficulty_sim.py` method) shows TTK 2–5 on normal enemies per floor, bosses surviving a real rotation, and no boss inversion; plus a played full run by Garth.

- ✅ **Second trap type** — **Venom Dart Snare** (`dart_trap`): wall-mounted, harder to spot (Agility 4+ disarms vs 3+ for spikes), damage + Poison (3t); generator scatter from depth 2 down, set-piece placements, canvas structure art, auto-explore avoidance, Legend + hover-hint entries.

## Phase 4 — "Polish & hardening" (P4) — DONE Nov 14, 2026 (working tree; tests 69/69, tsc + build clean, sim extended)
Closes the remaining Phase 2 follow-ups (difficulty select, key rebinding, save version field + per-slot corruption isolation, ending credits, save-slot completion stamp). P1 tuning is untouched: the base constants remain the Standard tier.
- ✅ **Difficulty select** — three tiers (Story / Standard / Hardened) picked on the New Adventure flow and changeable mid-run in Settings. Multipliers (enemy HP / enemy ATK / XP): Story ×0.75 / ×0.85 / ×1.15, Standard ×1.0 across the board, Hardened ×1.25 / ×1.15 / ×1.10. HP/ATK scaling funnels through `scaleEnemyForDifficulty` inside `createEnemy`, so every spawn path (regular, story bosses, elites, side bosses via promote+tune, Abyss) is covered; the XP multiplier applies inside `grantXpAndCheckLevel`. Difficulty is per-run, stored in the save bundle (`difficulty` field; legacy saves default to Standard); a mid-run change applies to newly encountered enemies/floors — already-spawned enemies keep their stats. Current tier shows in the pause menu.
- ✅ **Save versioning + per-slot corruption isolation** — `SAVE_VERSION` (= 1) in `src/game/saveSlots.ts`, stamped into every bundle on every save path (manual, zone-transition, autosave). Missing version = legacy bundle, hydrates normally; a newer version is refused gracefully with a visible message; an unparseable/invalid slot renders as corrupted in the Title Screen list (delete still works) without breaking the list or other slots. Slot keys unchanged (`ashen_glyph_save_v2_slot_N`).
- ✅ **Key rebinding** — a keymap in the per-device settings blob (merged over defaults, so old blobs hydrate): all 14 single-key actions from the App keyboard handler (movement ×4, wait, interact, explore, rest, quick heal, skills, inventory, journal, map, guide). Settings UI: click a row, press a key; Escape cancels; binding onto a taken key swaps the two; Reset Defaults restores the factory map. Arrow keys always move and Enter always interacts (hardcoded fallbacks); number-row skills/runes, Tab and Escape stay fixed. The handler routes through the pure `resolveKeyAction` resolver.
- ✅ **Credits roll + completion stamp** — `CreditsScreen`: slow auto-scrolling credits, dismissed by any key/click, reachable from a Title Screen "Credits" button and from the Ending Screen. Completion stamp: reaching the ending records `completedAtMs` on the active save (first stamp wins, survives Abyss continuation and re-saves); the Title Screen slot list marks stamped slots "✦ Completed".
- Still open from the Phase 2 follow-up list (not this phase): text size / colourblind-safe signalling, contextual tutorial coach-marks at first telegraph/inscription/prodigy sighting.

## Phase 5 — "Ascension" (P5) — DONE Nov 14, 2026 (working tree; tests 86/86, tsc + build clean, sim extended)
Endgame modes, un-parked now that P1 difficulty is coherent. The Phase 4 scaling funnel stays the single application point: cycle multipliers compose multiplicatively with the difficulty tier inside `scaleEnemyForDifficulty` / `scaleXpForDifficulty`, so at Standard + cycle 0 every value is exactly the Phase 4 game (test-pinned). All new bundle fields are optional-with-defaults — `SAVE_VERSION` stays 1 and pre-P5 saves load unchanged.
- ✅ **New Game+ / Ascension cycles** — the Ending Screen gains "Begin New Game+ — Cycle N+1": the world regenerates completely fresh (towns, dungeons, quests, merchants — the same construction as a new expedition) while the player keeps level, attributes, skill points/skills, equipment, inventory, gold, glyph dust, and companion. Per-cycle run state (kills, turns, flags, quests) resets; difficulty, hardcore, and the completion stamp carry over. Cycle scaling: enemy HP ×(1 + 0.35·cycle), ATK ×(1 + 0.25·cycle), XP ×(1 + 0.20·cycle) — Malakor at Standard is 1000 HP on cycle 0, 1350 on NG+1, 2050 on NG+3. The cycle is stored in the bundle (`ngPlusCycle`), shown in the Title Screen slot summary and the pause stats.
- ✅ **Hardcore (permadeath) mode** — a "Hardcore — death is final" toggle on the New Adventure flow beside the difficulty selector, stored per-run (`hardcore`), settable only at run creation (Play Again keeps the mode of the run it replaces, mirroring difficulty). On death the bundle is stamped `deadAtMs` + a death note (floor / zone), the Title Screen renders the slot "☠ Fallen — Cycle N · Fell on Floor F · …" with Load disabled and Delete working, load attempts are refused in App as defence-in-depth, and the run's Hall of Fame chronicle entry is recorded by the normal fallen path. Hardcore runs may still ascend on victory; death at any cycle is final. Non-hardcore death flow is untouched.
- ✅ **Lifetime stats** — a per-device record outside the save bundles (`src/game/lifetime.ts`, key `elfstory-lifetime`, merge-over-defaults like settings): expeditions started, victories, deaths, total kills, deepest floor reached, highest NG+ cycle reached. Updated at the real event funnels — run start + ascension, the once-per-ending chronicle write (victory/death + depth + cycle), the single enemy-death funnel (kills; the Grave Husk Deathless cheat earns no credit), and a live deepest-floor tracker. Displayed as a "Lifetime" section on the Hall of Fame screen.

## Phase 6 — "Reach & refinement" (P6) — DONE Nov 14, 2026 (working tree; tests 80/80, tsc + build clean)
Un-parks gamepad support and PWA/offline install, and closes the last Phase 2 follow-ups (text size, colourblind-safe signalling, contextual coach-marks). No gameplay-balance changes; P1 tuning and all Phase 4 behaviour untouched.
- ✅ **Gamepad support** — standard-layout mapping (DPad + left stick move with deadzone + ~170 ms hold-repeat; A interact, B cancel/back mirroring the Escape cascade, X map, Y journal, LB/RB cycle target, Start pause, Back auto-explore). Polling feeds the same action dispatch and gating as the keyboard; the mapping/repeat logic is a pure, unit-tested module (`src/game/gamepad.ts`). A "🎮 Gamepad" indicator joins the Title Screen control hint while a pad is connected. Unit-tested only — no gamepad hardware in the build environment.
- ✅ **PWA / offline install** — `public/manifest.webmanifest` (standalone display, #0B0D12 theme, SVG citadel-and-sun emblem at `public/icons/emblem.svg`), `public/sw.js` (cache-first app shell `elfstory-shell-v1`, old-cache cleanup on activate, cached-index fallback for navigations), and a protocol-guarded registration in `index.html` (http/https only, so the file:// standalone never registers or throws).
- ✅ **Accessibility settings** — text size (Compact / Standard / Large) applied as a root font scale, and pattern signals (default on): telegraphed danger tiles also draw a "!" marker, so attacks are never signalled by colour alone; off restores the exact prior rendering. Both live in the settings blob and hydrate over pre-P6 blobs.
- ✅ **Contextual coach-marks** — three one-time-per-device hints at real event points: the first telegraphed Heavy Strike priming, the first inscription gained (the single `addItemToPlayer` funnel), and the first Prodigy point earned (the single XP-grant funnel). Each renders as a log line + a dismissible toast in the zone-banner idiom; flags follow the tutorial's per-device pattern (`src/game/coachMarks.ts`).
- ✅ **Flaky-test fix** — the Phase 3 set-piece frequency test (≥25/30 unseeded floors; true rate ~92–97%) is now deterministic: a fixed 200-floor sample per biome under a seeded PRNG (Math.random swapped for the test only, always restored), asserting ≥85% — safely below the measured rates (barrow 91.7%, mire 93.3%, frost 97.3%, main 92.0% unseeded, n=300). Production generation behaviour unchanged; the phase3 file passes 5 consecutive runs.

## Phase 7 — "Fix pack" (P7) — DONE Nov 14, 2026 (implemented; tests + live smoke by Muse)
Small fixes from the final audit of the shipped P5+6 build — no new features, no balance changes.
- ✅ **Ending Screen reachable after reload** — completed runs can return to the Ending Screen from the pause menu (gated on `worldFlags.malakorDefeated`), so the NG+ ascend survives save/reload instead of existing only in the live victory moment.
- ✅ **Offline boot works** — the service worker runtime-caches same-origin assets and the cache name is bumped to `elfstory-shell-v2`; an installed PWA now boots offline, not just its HTML shell.
- ✅ **No frozen zombie loads** — save bundles with hp ≤ 0 load into GAME_OVER instead of a frozen state.
- ✅ **Quest rewards can't double-pay** — the `complete_quest` handler refuses to pay rewards for an already-completed quest (defence-in-depth behind the dialogue gating).
- ✅ **Stacked-consumable selling** — selling a stack sells one unit at the shown price (was: the whole stack was removed for one unit's price).
